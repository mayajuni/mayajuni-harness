# Starter Workflow

1. Clarify the requested outcome and constraints.
2. Inspect the relevant files or runtime state before editing.
3. Make the smallest change that satisfies the request.
4. Run a narrow validation step tied to the changed area.
5. Summarize the result and any remaining risk.
